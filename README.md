# Радио на WPF

Простое настольное приложение на **WPF** для воспроизведения интернет-радио по ссылке.

## Описание

Программа содержит:

- поле для ввода ссылки на радиопоток;

- кнопку **Play** для запуска воспроизведения;

- кнопку **Stop** для остановки воспроизведения.

Для воспроизведения используется библиотека **NAudio**.

## Структура проекта

В проекте используются основные файлы:

- `MainWindow.xaml` — разметка окна;

- `MainWindow.xaml.cs` — логика кнопок и воспроизведения;

- `README.md` — описание проекта.

Также на всякий случай в **корень проекта** добавлен файл `.exe`.

## Интерфейс

В окне приложения находятся:

- текстовое поле для ссылки на радио;

- кнопка **Play**;

- кнопка **Stop**.

## Используемая библиотека

Для работы приложения требуется пакет **NAudio**.

## Запуск

1. Открыть проект в **Visual Studio**.

2. Убедиться, что пакет **NAudio** установлен.

3. Запустить проект.

4. Ввести ссылку на радиопоток.

5. Нажать **Play**.

6. Для остановки нажать **Stop**.

## Проверенная ссылка

Одна из рабочих ссылок, на которой приложение запускалось:

```text
http://stream128.melodiafm.spb.ru:8000/melodia128
```

## Примечание

Не каждая ссылка на радио подходит для запуска. Приложению нужна именно **прямая ссылка на аудиопоток**. Если указать ссылку на обычную web-страницу радиостанции, воспроизведение не начнётся.
